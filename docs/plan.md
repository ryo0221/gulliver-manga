# ガリヴァー旅行記 漫画連載 企画（fiction-manga@1.1.0）

Nov 14, 2026 · @Ryo Tsutsui

ガリヴァー旅行記を全4部・24話・各16ページのWeb連載にする企画です。工程は `fiction-manga@1.1.0`（workflow-definitions main `32014ad`）の13工程をすべて通り、この文書はその最初の2工程「進め方」「企画」の成果物3つ（進め方・企画書・画作りガイド）の草案です。

- 典拠は英語の原文（Project Gutenberg #829）だけにし、翻訳と映画の見た目は使いません。これはガリヴァーの世界の再現（GV1〜GV7）と同じ方針です。
- 世界と舞台、人物の工程では、再現で作った地図6枚、実寸のCAD/BIM、人物と馬のrigを正本の材料として使います。
- AIが確かめる条件（`process.complete`・`process.ai-scope`・`concept.complete`・`art.layers-defined`・`art.samples-sourced`）は、この草案の中身で満たすように書きました。人が確かめる条件（`process.approved`・`concept.approved`・`art.approved`）は、2026-11-14に作者が推奨どおりで承認しました。

## 進め方

13工程をすべて通り、省く工程はありません。進め方から脚本までは作品全体と4つの部ごとに進め、ネームから学びまでは話ごとに繰り返します。

### 工程の順

進め方と企画の後、人物と世界と舞台を並行して進めます。筋と構成は全体を先に作り、脚本は部ごとに作ります。連載中は、公開する話の2話先まで、脚本を受け入れた状態を保ちます。

&#91;embedded content: 工程の順 · 13工程、話ごとに7工程を繰り返す\]

1. 進め方と企画を作品全体で一度受け入れる。
2. 人物、世界と舞台を部ごとに作る（第1部から）。
3. 筋と構成を4部通して作る。結末までの伏線をここで決める。
4. 脚本を部ごとに作る（第1部の6話から）。
5. ネーム→ラフ→線画→仕上げと写植→通読→出版準備→学びを、話ごとに繰り返す。学びは次の話のネームの前に読む。

### 省く工程

工程は省きません。舞台の3Dモデルは任意ですが、再現で作ったものを使います。モデルを作らない場所（航海中の海、グラブダブドリッブの館など）は、地図と舞台の設定画だけで向きと縮尺を確かめます。

### AI に頼むこと

| 工程 | AIに頼む範囲 |
| --- | --- |
| 企画・筋と構成・脚本 | 文章の草案と別案を書く。採らなかった案は残さない。台詞の決定は作者 |
| 人物・世界と舞台 | 本文の値の表、地図、3Dモデル、rigを作る・直す（再現で作ったものの続き） |
| ネーム | 人物の配置とカメラを3Dの上で提案し、コマ割りは変更提案（JSON）で出す。採否は作者 |
| ラフ | 3Dから下絵を書き出す（レイヤー「下絵（3D）」） |
| 線画・仕上げ | 決定（2026-11-14）：AIの画像生成で各レイヤーの清書を提案し、作者が採否と局所の直しをする |
| 写植 | 台詞を吹き出しへ置く。台詞の文は変えない |
| 通読 | 設定との食い違い、表記の揺れを指摘として書く。直すかは作者 |

- 話やページごとに範囲を変えるときは、その話のネームの前に作者が決め、その話の出力の記録に書きます。
- 画像生成の道具：Playgroundには画像生成が入っていません。使う道具はCodexです（2026-11-14に作者が指定）。生成したPNGをPlaygroundの変更提案として取り込みます。
- 生成を断られた・失敗したときは、次の順で代えます。(1) 指示と渡す参照を変える。(2) 作者がそのレイヤーを描く・直す。(3) そのコマを3Dのpath tracingの絵（Render image）で代え、写植の記録に理由を書く。

### 出口

自分のサイトでのWeb連載（私家版）を推奨します。締め切りと外の規定が無いので、Editorの能力を強めながら進められます。投稿サイトや公募へ出す場合は、その規定を企画書の「出口と規定」に足します。

## 企画書

### ログライン

船医レムュエル・ガリヴァーは、小人の国、巨人の国、空飛ぶ島、理性ある馬の国を巡る。そのたびに「大きさ」と「人間」を測る物差しを失い、ついに自分の家族のもとへ帰れなくなる。

### テーマ

- **TH-01 大きさは物差しで変わる**：同じ一人が、小人の前では巨人、巨人の前では虫になる。実寸の比（1/12と12倍）を絵でそのまま見せる。
- **TH-02 人間は自分を理性的だと思いたがる**：宮廷、学士院、戦争の風刺。笑いとして描き、説教にしない。
- **TH-03 旅するほど帰れなくなる**：各部の終わりの帰郷が、部を追うごとに苦くなる。

### 読者

原作を「小人の国」しか知らない中高生から大人です。絵で見る大きさの違いの楽しさと、第3部・第4部の風刺と苦い結末までを、通して読める形を求めています。

### 長さ

全4部・24話、各話16ページ（合計384ページ）が目安です。各部6話です。

| 部 | 話 | 大きさの比（本文） | 再現で作った舞台 |
| --- | --- | --- | --- |
| 第1部 リリパット | 1〜6 | 住人は約146 mm（1/12） | ミルデンドウの城壁と王宮、古い神殿、運搬機、ブレフスキュの艦隊 |
| 第2部 ブロブディンナグ | 7〜12 | 住人は約21 m（12倍） | 農家の食卓、寝室の箱と旅行用の箱、寺院の塔、王宮の大広間 |
| 第3部 ラピュータほか | 13〜18 | 人と同じ | 直径7,837 yardsの飛ぶ島と磁石、ラガードの学士院と言葉を作る枠 |
| 第4部 フウイヌム国 | 19〜24 | 馬と人 | 主人の家とヤフーの小屋、馬とヤフーのrig |

### 結末までのあらすじ

1. **第1部（1〜6話）**：難破したガリヴァーは、小人たちに縛られて目を覚ます。宮廷に取り立てられ、ブレフスキュの艦隊を引いて戦争を止める。しかし、王宮の火事を尿で消したことと、敵国を滅ぼすことを断ったことで罪を問われる。両目を潰す判決を知ってブレフスキュへ逃れ、拾ったボートで英国へ帰る。
2. **第2部（7〜12話）**：上陸した巨人の国で農夫に拾われ、娘グラムダルクリッチに世話されながら見世物にされる。王妃に買い取られ、王へ英国を誇らしげに語るが、「地を這う小さな嫌らしい虫」と断じられる。旅行用の箱ごと鷲にさらわれて海へ落ち、船に拾われて帰る。帰郷しても、しばらく家族が小さく見える。
3. **第3部（13〜18話）**：海賊に追い放たれた島から、空飛ぶ島ラピュータへ引き上げられる。理論に夢中で暮らしを顧みない人々を見、地上のラガードでは役に立たない研究をする学士院を訪ねる。魔術師の島で死者と話し、ラグナグでは死なない人「ストラルドブラグ」の老いを知る。日本を経て帰る。
4. **第4部（19〜24話）**：船員の反乱で置き去りにされ、理性で暮らす馬フウイヌムの国で、獣じみた人間ヤフーと見分けられないことに苦しむ。主人の馬に英国の戦争や法を語るうち、人間を嫌うようになる。会議の決定で国を追われ、家族のもとへ帰る。しかし妻子の臭いに耐えられず、厩で馬と話す日々を送る（最終話）。

### 出口と規定

- 自分のサイトでのWeb連載です。週に1話を目安にし、各部の間に休みを入れます。
- 原稿はA4縦、ページごとにPNGと、話ごとにPDFで書き出します。
- 各話の最後にAIの関わり（工程、道具、採ったレイヤー）を記します。
- 原作（Gutenberg #829）の本文は、本作のために新しく訳します。既存の日本語訳は引用しません。

### 文字の決まり

- 台詞は日本語で、横書きにします。今の漫画ワークスペースは横書きだけで、縦書きとルビに対応していないためです。
- ページとコマは左から右へ読みます。横書きの台詞と、Webで横にめくる読み方に合わせます。
- 台詞はゴシック体、ナレーション（ガリヴァーの手記）は明朝体にします。大きさは本文9 pt相当、叫びは最大14 pt相当です。
- 擬音は手書きで、LY-08（効果）に描きます。
- ルビは使いません。固有名は初出で「ブロブディンナグ（Brobdingnag）」のように原語を添え、表記は辞書に合わせます。
