# 第1話「人の山」ネーム（16ページ、AI の提案）

正本は `part1/name/artifacts/` の Design 原稿 `gm1-ep01-name` とコマ表 `gm1-ep01-name-panels` です。この文書はコマ表を書き出した文章版です。ページの絵は `part1/name/pages/` にあります。

fiction-manga@1.2.0 の「舞台で組む」（storyboard.staged）に合わせ、コマごとに 3D の舞台（デジタルツイン）で人物の位置・向き・ポーズとカメラの位置・注視点を決めました。カメラの絵をコマの枠に切り抜いてコマの下に敷き（アタリ）、真上からの配置図を `part1/name/stage/plans/` に置いています。座標は舞台のモデルの版の座標（mm、z が上、北が +y）です。舞台の記録は `part1/name/stage/ep01-stage.json` です。

書式：コマごとに「大きさ｜カメラの目 高さ（地面からの実寸）」、カメラの立つ台、カメラの向き、絵のメモ、文字にする行（ナレーション・台詞・擬音）、3D の舞台（カメラ、注視点、画角、人物、群衆、アタリと配置図）。★は大きさの違いを見せるコマ（AR-05、小人の目の高さから撮る）。
